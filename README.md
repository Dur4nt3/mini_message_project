# Mini Message Board

## Mini Message Board - Overview

This is the second project of the "NodeJS" course within "The Odin Project".

This project acts as an introduction to ExpressJS and EJS (template engine).

In particular, this project aims to create a message board application where you can view and post messages.

**You can view this project at: https://minimessageproject-production.up.railway.app/.**

## Skills Demonstrated

- EJS (Template Engine)

- Using a view engine in ExpressJS

- Using EJS to create HTML templates

- Rendering HTML templates with ExpressJS

- Using PostgreSQL

- MVC (Model-View-Controller) Pattern
